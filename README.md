# Bayesian Shrinkage

Байесовская оценка способности бейсболистов по малым выборкам (первые 45 подач) на реальном датасете Эфрона–Морриса. Сравнивается наивная оценка максимального правдоподобия и байесовская оценка со сжатием к априорному среднему — показано, что сжатие кратно снижает ошибку прогноза на остатке сезона.

Дополнительно исследуется, как сила априорного распределения влияет на качество прогноза, и как байесовская оценка ведёт себя при росте объёма данных. Построены credible-интервалы и проанализирована их устойчивость при малых выборках.

## Что внутри

- Байесовская оценка с Beta-априорным распределением
- Сравнение с ОМП по SSE
- Влияние силы априорного (κ) на качество
- Credible-интервалы
- Асимптотика байесовской оценки при росте n
